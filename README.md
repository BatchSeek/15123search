──────────────────────────────
一、软件能做什么？
──────────────────────────────
选中电脑里的一个文件夹，输入关键词，就能找出所有「内容里包含
这个词」的文档，比如 Word、Excel、PPT、PDF、记事本等。

搜索范围可以自己组合：首页「搜索内容」与「搜索文件名」两个
复选默认都勾选，你可以只搜内容、只搜文件名，或两者都搜。

搜索结果会列出：
  · 文件名称
  · 完整的文件路径
  · 内容摘要（勾选「搜索内容」时关键词高亮显示）

──────────────────────────────
二、怎么用？（三步搞定）
──────────────────────────────
第 1 步：双击运行「15123搜索.exe」
第 2 步：点「选择文件夹」，选你想搜索的目录（也可以选整个磁盘）
第 3 步：在搜索框输入关键词，回车或点「搜索」

──────────────────────────────
三、批量处理文件
──────────────────────────────
批量处理工作区以表格列出待处理文件（可单独移除 / 清空 /
重新选择路径或添加文件），功能按标签页分为三组，默认显示
「文件整理」（页面随窗口最大化自动变宽，各功能
按钮在小框内居中）：

【文件整理】
  · 批量重命名 —— 预览新名，非法名 / 批次内重名 / 目标已存在
    标红并拦截整批；两阶段改名防链式冲突，执行后可一键撤销，
    设置项为「名称+输入框」成对同行排版
  · 文件归档整理 —— 按扩展名 / 文件类型 / 修改日期 / 日期+时刻
    自动分文件夹归类，可选复制或移动，同名自动加序号
  · 文件拆分 —— 把大文本文件按行数或字数拆成多个小文件，
    Word 文档可提取正文后拆分
  · 文件合并 —— 多个文本文件合并成一个（可选是否保留各文件
    表头、指定目标编码）；全是 docx 时自动合并为
    Word 文档，否则合并为 txt
  · 文本编码转换 —— 自动探测源编码，批量转为 UTF-8 / GBK /
    UTF-8-BOM；默认先备份再改，报告里可一键还原，
    Word 文档可提取正文转换
  · 文件清单导出 —— 把工作区文件导出成 CSV / TXT（可自选列）
  · 复制文件路径列表 —— 导出全部文件的完整路径列表
  · 文件对比 —— 任选两个文件，逐行对比内容差异，新增 / 删除 /
    修改的行用不同颜色标出，支持 Word 与 PDF 文档

【内容处理】
  · 查重清理 —— 按 MD5 找出完全相同的文件，预览重复分组与
    浪费空间，可只保留每个分组最新 / 最旧 / 路径最短的一个，
    其余移入回收站或移到指定文件夹
  · 批量替换文件内容 —— 先预览匹配数与上下文再执行；默认
    先备份再改（可一键还原），只读文件自动跳过。支持
    docx 原地替换与 doc / PDF 提取正文替换，并提供「按行
    配对替换」：勾选后查找内容第 1 行替换为替换内容第 1 行、
    第 2 行替换第 2 行……一次替换多组内容
  · 批量改页眉页脚 —— 给 Word 批量添加 / 替换 / 清除页眉页脚，
    可设置页眉页脚文字的字体、字号、颜色与靠左 /
    居中 / 靠右位置，并支持 PDF
  · 批量加页码 —— 给 Word 批量插入页码（页眉或页脚，可选
    格式）；支持 PDF，可设置页码字体、字号、颜色、
    从第几页开始加，预设格式与 WPS 一致，还可自定义格式
    （如「第 X 页 共 Y 页」）
  · 批量加水印 —— 支持文字水印与图片水印，
    可设置透明度、大小与位置；文字可设置字体、字号、颜色；
    支持 docx 与 PDF（doc 需先用 Word 另存为 docx）
  · Excel 批量处理 —— 多个工作簿合并成一个、批量删除空行、
    批量修改工作表名（按原序号或加前缀），结果另存不覆盖
    原文件；新旧版表格（xlsx / xls）都支持

【安全与属性】
  · 属性与时间戳 —— 批量设置 / 取消只读、隐藏属性，批量修改
    修改时间（可选同时改访问时间）
  · 文件加密 / 解密 —— AES-256 加密（密码 + PBKDF2 派生密钥），
    加密生成 .enc 文件并保留原文件；解密输错密码会明确提示
  · 元数据清理 —— 清除 Word / Excel / PDF / 图片里的作者、
    备注、相机信息等隐藏元数据（图片会同时去掉 EXIF 旋转）
  · 移入回收站 —— 把文件送进回收站（可还原，不是彻底删除）

六、注意事项
──────────────────────────────
  1. 本软件为单文件绿色版，不要删除同目录下的任何内容；
     直接运行 exe 即可，不需要额外的运行库。
  2. 首次运行时加载稍慢（正在初始化界面），属正常现象。
  3. 软件需要系统自带的 Edge WebView2 组件（Win10/11 一般已内置），
     若窗口无法打开，会自动回退到系统浏览器访问，功能不受影响。
  4. 搜索整个 C 盘等系统目录时，建议同时关注扫描进度，
     遇到无权限的文件夹会自动跳过。
  5. 激活码请妥善保管，不要分享给他人：一码只能绑一台电脑，
     被他人抢先绑定后你自己将无法使用。
  6. 文件加密的密码请务必牢记：密码丢失将无法解密，
     软件没有后门也无法找回。
